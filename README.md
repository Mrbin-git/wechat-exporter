# 微信聊天记录导出（WeChatExport）

> 版本 **1.0.0** · Windows x64 · 绿色免安装 · 全程本机运行

把你自己电脑上 **微信 4.x** 的聊天记录，导出成可以离线翻看的 HTML 页面、Excel 能直接打开的 CSV、以及 JSON / TXT / XLSX。双击一个 exe，浏览器里点三步，就能拿到一份可以直接归档、打印、交给律师或留作纪念的聊天记录。

---

## 它是什么

微信把聊天记录加密保存在本机数据库里，正常途径只能一条条翻、不能整段导出。这个小工具做三件事：

1. 找到你电脑上的微信安装位置、聊天数据目录和账号；
2. 在本机取出数据库密钥，把数据库**解密出一份临时副本**；
3. 把副本读成一条条消息，按你选的格式写出到输出目录，然后删掉临时副本。

它**不是**微信官方工具，也**不是**云服务：没有服务器、没有账号体系、导出过程不产生任何网络请求。

## 它不做什么

- 不解密、不导出**别人**手机或电脑上的数据，只读当前这台机器上、当前 Windows 用户能访问的文件；
- 不修改微信的任何文件（数据目录以只读方式打开，解密副本写在另外的临时目录）；
- 不上传、不联网、不写注册表、不安装服务、不驻留后台；
- 不支持微信 3.x，不支持企业微信，不支持手机端数据库；
- 不破解、不绕过任何登录验证——**必须是你自己已经登录的微信**。

## 功能列表

| 能力 | 说明 |
| --- | --- |
| 自动发现微信 | 读注册表 `HKCU\Software\Tencent\Weixin` 的 `InstallPath`，再扫描各盘符常见安装路径，定位 `Weixin.exe` 与 `Weixin.dll` |
| 自动发现数据目录 | 读 `%APPDATA%\Tencent\xwechat\config\*.ini` 里记录的路径（例如 `D:\WeChat\xwechat_files`），并兜底扫描文档目录与各盘符根目录，支持自定义盘符 |
| 多账号 | 同一台机器上登录过的多个账号会全部列出，可分别导出 |
| 密钥自动获取 | ①本机 DPAPI 加密缓存 ②扫描正在运行的 `Weixin.exe` 进程内存 ③手动输入 64 位十六进制密钥 |
| SQLCipher 4 / WCDB 解密 | PBKDF2-HMAC-SHA512（256000 轮）→ AES-256-CBC，页大小 4096，逐页校验 |
| 消息解析 | 文本、图片、语音、视频、文件、表情、链接、引用、位置、名片、小程序、视频号、系统消息 |
| 媒体还原 | 图片 `.dat`（V2 容器）解密还原为 jpg/png/gif/webp；文件与视频按原样复制 |
| 五种导出格式 | HTML（可离线浏览，含图片）、CSV（UTF-8 BOM，Excel 直接打开）、JSON、TXT、XLSX |
| 会话筛选 | 默认全部会话，也可只勾选某几个会话 |
| 时间范围 | 命令行支持 `--since` / `--until` 时间戳过滤 |
| 本地网页界面 | 启动后自动在 `127.0.0.1` 的随机端口起服务并打开默认浏览器 |
| 命令行模式 | `--scan` 输出环境 JSON；`--export` 无界面批量导出 |
| 隐私保护 | 密钥只写本机 DPAPI 加密缓存；临时解密目录导出后自动删除 |

## 三分钟上手

**前提：微信 4.x 已经登录并保持运行。** 这是最重要的一条——工具需要从正在运行的微信进程里取密钥。

1. **解压并双击** `WeChatExport.exe`。程序会在本机起一个临时网页服务，并自动用默认浏览器打开界面（地址形如 `http://127.0.0.1:52341/`）。同时会有一个黑色控制台窗口，那是程序的"主机"，**不要关**，用完再关。
2. **第 1 步「检测环境」**：点 **自动检测微信与账号**。几秒后下方会显示微信版本、安装目录、运行状态、数据目录和账号数量。
   - 如果"运行状态"显示 *未运行*，请先打开并登录微信，再点一次。
   - 如果"账号"显示 *未找到*，多半是数据目录不在默认位置，请见 [FAQ](docs/FAQ.md)。
3. **第 2 步「选择账号与会话」**：在 **账号** 下拉框里选一个账号；想只导出某几个会话，就点 **加载会话列表**（首次需要解密，约 1–3 分钟），然后取消勾选 **全部会话**、勾选需要的会话。不改也行，默认导出全部。
4. **第 3 步「导出设置并开始」**：格式默认已勾选 **HTML**；需要表格就再勾 **CSV** 或 **Excel**。**输出目录**留空即导出到 `文档\微信导出\年月日-时分秒`。点 **开始导出**。
5. 等进度条走完，点 **打开输出目录**。双击 `index.html` 就能离线浏览；`会话名.csv` 可以直接用 Excel 打开。

确人完成后，点界面右上角 **退出**，或直接关掉控制台窗口。

## 自动取密钥失败时（手动模式）

如果界面提示「未能在微信进程内存中找到密钥特征」，可以在第 2 步的**密钥**输入框中
粘贴 64 位十六进制密钥（32 字节），再点「加载会话列表」。命令行等价写法：

```powershell
WeChatExport.exe --export --account wxid_xxx_abcd --out D:\out --formats html --key <64位hex>
```

密钥只在本机内存中使用；自动获取成功后会以 Windows DPAPI 加密缓存到
`%LOCALAPPDATA%\WeChatExporter\keys.dat`，下次启动无需重复获取。

## 构建方法（可选）

发布包已经打包好，普通用户不需要看这一节。想自己从源码构建：

**构建机要求**：Windows x64、Python 3.11+ 与 pip。首次构建时脚本会自动把 `pyinstaller`、`cryptography`、`zstandard`、`openpyxl`、`pillow` 安装到项目内的 `vendor\` 目录（不污染系统 Python）。

```powershell
# 在项目根目录执行
pwsh -File tools\build.ps1

# 指定解释器 / 输出目录 / 单文件模式
pwsh -File tools\build.ps1 -Python "C:\Python312\python.exe" -Out dist -OneFile
```

脚本做的事：探测 Python → 缺依赖就装到 `vendor\` → 调用 PyInstaller 以 `--onedir`（默认）打包 `src\wexport\__main__.py`，把 `ui.html`、`app.js`、`style.css` 三个前端文件一并塞进包内 → 把 `README.md`、`LICENSE`、`THIRD-PARTY-NOTICES.md` 复制到产物目录。

产物：

```
dist\WeChatExport\
├─ WeChatExport.exe        ← 双击这个
├─ _internal\              ← 依赖与前端资源，勿删
├─ README.md
├─ LICENSE
└─ THIRD-PARTY-NOTICES.md
```

自检（不打开界面，只打印环境 JSON）：

```powershell
.\dist\WeChatExport\WeChatExport.exe --scan
```

**给最终用户的发布方式**：把整个 `dist\WeChatExport\` 文件夹压缩成 zip 分发即可。不要只发 exe——`_internal\` 目录是运行必需。

## 命令行（可选）

适合脚本化备份或不想开浏览器的情况。同样需要微信已登录。

```powershell
# 1) 只看环境：输出微信安装目录、数据目录、账号列表的 JSON
WeChatExport.exe --scan

# 2) 直接导出：指定账号、输出目录、格式
WeChatExport.exe --export --account wxid_example_9f3a --out "D:\备份\微信" --formats html,csv
```

| 参数 | 说明 |
| --- | --- |
| `--scan` | 扫描环境并输出 JSON，找到账号时退出码 0，否则 1 |
| `--export` | 执行一次导出后退出 |
| `--account <名称>` | 账号**目录名**（形如 `wxid_xxx_9f3a`）或 wxid；省略或匹配不到时用第一个账号 |
| `--out <目录>` | 输出目录，不存在会自动创建 |
| `--formats html,csv` | 逗号分隔，可选 `html` `csv` `json` `txt` `xlsx`，默认 `html` |
| `--chats a,b` | 只导出指定会话（会话 username，逗号分隔） |
| `--since` / `--until` | 起止时间（Unix 时间戳，秒） |
| `--no-media` | 不导出图片/文件，只出文字 |
| `--no-system` | 不包含系统消息 |
| `--port 8765` | 固定网页端口（默认随机） |
| `--no-browser` | 启动服务但不自动打开浏览器 |

排查用的两个环境变量：`WEXPORT_DEBUG=1` 在出错时附带完整调用栈；`WEXPORT_KEEP_WORK=1` 让命令行导出**保留**临时解密目录（默认导出结束即删）。GUI 模式始终自动清理临时目录。

## 隐私与合规声明

- **全程本机运行**：程序只在 `127.0.0.1` 上监听一个随机端口供本地浏览器访问，不连接任何外部服务器，不上传任何聊天内容、联系人、密钥。断网也能完整使用。
- **只读微信数据**：数据目录以只读方式打开，不写、不改、不删；不会影响微信正常使用。
- **临时文件可控**：解密副本写到 `%LOCALAPPDATA%\WeChatExporter\work\`，导出成功后自动删除；命令行模式下设 `WEXPORT_KEEP_WORK=1` 才会保留。若在取密钥/解密阶段异常中断，该目录可能残留，请手动删除。
- **密钥仅存本机**：自动获取到的密钥以 Windows DPAPI 加密后存于 `%LOCALAPPDATA%\WeChatExporter\keys.dat`，只有当前 Windows 用户能解开；工具不发送、不联网校验密钥。
- **导出结果由你负责**：导出文件是明文，包含你和对方的真实对话。请自行保管、加密或销毁，不要上传到网盘、群聊或任何第三方平台。

**合规边界**：本工具面向"导出本人设备上本人账号的聊天记录"这一用途，例如个人备份、维权取证、离职工作交接。导出他人聊天记录、导出后公开传播他人隐私，可能违反《个人信息保护法》《民法典》人格权编等规定，也可能违反你与腾讯之间的服务条款。相关法律背景与风险说明见 [docs/RISKS.md](docs/RISKS.md)。

## 已知限制

下面是使用前应当知道的边界；每一项"为什么不做/什么时候做"的取舍记录在 [docs/LIMITATIONS.md](docs/LIMITATIONS.md)。

1. **只支持微信 4.x**：3.x 的数据库结构完全不同，本工具会明确报错，不会静默出错。
2. **必须微信已登录**：自动取密钥依赖运行中的微信进程，未登录时内存中没有可用密钥，工具会直接报错，请先登录再导出。
3. **不支持企业微信**（WeCom），其数据目录与加密方式不同。
4. **不同 Windows 用户会话会失败**：如果微信以用户 A 运行，而导出工具以用户 B（或以管理员身份另开会话）运行，读进程内存会失败；请以**同一个 Windows 用户**运行本工具。
5. **密钥缓存换了电脑就不可用**：`keys.dat` 由 DPAPI 绑定当前 Windows 账户，复制到别的电脑解不开，需要重新自动获取或手动输入。
6. **部分图片是 HEVC（`.wxgf` 容器）**：工具没有内置解码器，会原样保留 `.wxgf` 文件并在 HTML 里给出可点击链接；需要查看时请自行用支持 HEVC 的工具处理。
7. **语音大多导不出音频**：桌面端常常不留本地语音文件；即便有，工具也只保留原始 SILK 数据、不做音频解码，页面上会标注"未找到本地文件"。
8. **未签名 exe**：首次运行可能触发 Windows SmartScreen 或杀毒软件提示，属于未购买代码签名证书的正常现象，详见 [FAQ](docs/FAQ.md)。
9. **手动密钥输入**：1.0.0 的图形界面在密钥步骤提供输入框，命令行也支持 `--export --key <64位hex>`（见 [USAGE](docs/USAGE.md)）；自动方式失败时的处理步骤见 [FAQ Q3](docs/FAQ.md)。
10. **异常中断可能残留临时目录**：正常导出成功会自动清理 `%LOCALAPPDATA%\WeChatExporter\work\`；如果在取密钥或解密阶段崩溃/被强杀，里面会留下明文数据库副本，请养成手动检查并删除的习惯。
11. **微信升级可能失效**：密钥的内存特征与客户端版本绑定，微信大版本更新后可能暂时取不到密钥，需等待工具更新。
