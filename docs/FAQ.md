## Q1 检测不到微信，一直显示"未检测到 / 未找到"

工具找微信的顺序是：先读注册表，再扫各盘符的常见安装路径。

1. 读 `HKCU\Software\Tencent\Weixin` 下的 `InstallPath` / `InstallDir`；
2. 读 `HKLM\SOFTWARE\Tencent\Weixin`、`HKLM\SOFTWARE\WOW6432Node\Tencent\Weixin` 以及 `...\Tencent\WeChat` 的同名值；
3. 到 `C:`–`H:` 各盘的 `Program Files\Tencent\Weixin`、`Program Files (x86)\Tencent\Weixin`（以及 `WeChat` 目录）去找 `Weixin.exe`。

**排查步骤**

- 确认你装的是**微信 4.x**，不是 3.x。3.x 的程序叫 `WeChat.exe`，本工具只处理 4.x 的数据结构。
- 打开任务管理器 → 详细信息，看看正在跑的进程叫 `Weixin.exe` 还是 `WeChat.exe`。是后者说明装的是 3.x，本工具不支持。
- 如果微信是绿色版/便携版、装在移动硬盘上，注册表里通常没有记录，自动发现会失败。这种情况下**手动密钥方式**也依赖 DLL 特征，建议改用标准安装包重装一遍再试。
- 装完别忘了：检测前**先把微信登录打开**。

## Q2 检测到了微信，但"账号"显示"未找到"

账号来自**数据目录**，不是安装目录。数据目录和安装目录默认不在一起。

工具这样找数据目录：

1. 读 `%APPDATA%\Tencent\xwechat\config\*.ini`，里面记录着你把聊天记录存到了哪（例如 `D:\WeChat\xwechat_files`）——这是最可靠的来源；
2. 再看 `文档\xwechat_files`、`文档\WeChat Files`、用户目录下的 `xwechat_files`；
3. 最后扫 `C:`–`H:` 各盘**根目录**下的 `xwechat_files`、`WeChat Files`、`微信文件`、`Weixin` 文件夹。

**为什么会找不到**

- 数据目录放在很深的层级，例如 `E:\我的资料\聊天\备份\xwechat_files`——第 3 步只扫根目录，扫不到；
- 数据目录在 `G:` 及以后的盘符——扫描只覆盖 `C:`–`H:`；
- 微信虽然装了，但从来没在这台机器上登录过（没有 `xwechat_files` 只有空壳）。

**怎么办**

1. 用微信自己的入口确认数据目录在哪：微信 → 左下角 **设置 → 文件管理 → 打开文件夹**，地址栏里那个路径就是。
2. 如果它在 `G:` 之后，或者层级很深，最省事的办法是：微信 → 设置 → 文件管理 → **更改**，把存储位置挪到 `D:\xwechat_files` 这类"浅路径"，重启微信让它迁移完，再点检测。
3. 检测前确认微信**处于登录状态**（未登录时配置文件可能还没写全）。

## Q3 密钥获取失败怎么办

工具取密钥的顺序是：

1. **DPAPI 缓存**：`%LOCALAPPDATA%\WeChatExporter\keys.dat`。用过一次之后，下次直接读这里，很快。
2. **内存扫描**：在 `Weixin.exe` 的内存里找那个 32 字节密钥缓冲区，与 `Weixin.dll` 里内嵌的 internal key 异或，再用数据库第 1 页的 HMAC 校验。这是首次使用时的主要路径，**耗时 1–3 分钟**。
3. **手动密钥**：你自己提供 64 位十六进制密钥。

三种都失败时，界面会给出具体错误，见 [USAGE.md 第七节](USAGE.md#七失败了怎么办)。最常见的三种：

| 错误 | 原因 | 处理 |
| --- | --- | --- |
| 未检测到正在运行的微信进程 | 微信没登录，或跑在别的 Windows 用户下 | 登录微信；用**同一个** Windows 账户运行工具 |
| 未能在微信进程内存中找到密钥特征 | 微信是 3.x，或版本太新特征变了 | 确认是 4.x；等工具更新；或用手动密钥 |
| 候选密钥均未通过校验 | 微信升级后内存布局改变 | 同上 |

**关于"手动密钥"**：核心模块（`keys.get_passphrase(..., manual_key=...)`）支持传入 64 位十六进制密钥，并会用数据库第 1 页校验是否匹配。1.0.0 的图形界面在密钥步骤提供**输入框**，命令行也支持 `--export --key <64位hex>`（`--dump-key` 只取密钥、不导出）。完整用法见 [USAGE.md](USAGE.md)。

自动获取失败时，按顺序尝试：

1. 在密钥输入框里粘贴 64 位十六进制密钥（32 字节；可从旧版工具输出或 `--dump-key` 取得），继续即可；密钥不对只会报"校验失败"，不会改动任何数据；
2. 完全退出微信（托盘图标右键退出），重新启动并登录，再点一次；
3. 确认工具和微信是同一个 Windows 用户、同一会话（不要一个用管理员身份另开）；
4. 如果之前手动删过 `%LOCALAPPDATA%\WeChatExporter\keys.dat`，不影响，工具会重新扫描内存；
5. 仍然失败，请把微信版本号与控制台报错一起反馈，等待适配。

## Q4 提示"微信未运行 / 先在微信登录"

**这是设计使然，不是 bug。** 微信 4.x 的数据库密钥在登录后才会派生并常驻进程内存，工具必须从运行中的微信进程里读它。微信没登录时，内存里没有密钥，缓存里也没有，就无从解密。

**正确姿势**

1. 打开微信，**完成登录**（扫码/自动登录都行）；
2. 让微信待在托盘或最小化都行，**不要退出**；
3. 回到工具页面，重新点 **自动检测微信与账号**；
4. 看到"运行状态：正在运行"再往下走。

**如果微信已登录还是报这个错**：八成是"跨用户会话"。比如你用管理员身份启动了工具，而微信是普通权限运行的——不同权限/不同登录会话下，`OpenProcess` 读不到对方内存。请关掉工具，用**普通双击**的方式重新打开，和微信保持一致。

## Q5 杀毒软件/SmartScreen 报警，是不是有毒？

大概率是**误报**。原因很具体：

- exe 是 PyInstaller 打包的，**没有购买代码签名证书**（一张签名证书一年几百到几千元），所以 Windows 不认识这个发布者，首次运行会弹"Windows 已保护你的电脑"。
- 工具会做两件杀软很敏感的事：**读取另一个进程的内存**、**批量解密文件**。这两条行为特征和某些恶意软件高度重合，启发式引擎容易误判。

**怎么处理**

- SmartScreen 蓝屏：点 **更多信息** → **仍要运行**。
- 杀软弹窗：确认来源是你自己下载的发布包 → 选择"允许"/"添加信任"。不要直接关掉杀软。
- 想更放心：把 exe 上传到 [VirusTotal](https://www.virustotal.com/) 看多家引擎结果——**注意上传的是程序文件，不是聊天记录**。PyInstaller 产物通常会有几家小厂报"Riskware/Packed"，属于打包器特征。
- 有源码洁癖的话，按 [README 的构建方法](../README.md#构建方法可选) 自己 `pwsh -File tools\build.ps1` 打一份，用自己的产物运行。

## Q6 导出很慢，正常吗？

分阶段看：

| 阶段 | 典型耗时 | 说明 |
| --- | --- | --- |
| 检测环境 | 1–5 秒 | 扫盘符可能稍慢 |
| 取密钥（首次） | **1–3 分钟** | 要扫进程内存并对每个候选做 256000 轮 PBKDF2，慢是正常的 |
| 取密钥（有缓存） | 1–2 秒 | 直接读 DPAPI 缓存 |
| 解密数据库 | 每 100 MB 约 10–30 秒 | 逐页 AES + HMAC，取决于 CPU 与磁盘 |
| 导出文字 | 很快 | 主要是读 SQLite |
| 导出媒体 | **最慢的一环** | 每张图都要 AES 解密；几十 GB 的附件目录可能几十分钟 |

**能明显加速的做法**

- 取消勾选 **导出图片/文件**——通常能省掉 80% 以上的时间；
- 只导出需要的会话（第 2 步勾选），不要全量；
- 把微信数据目录和输出目录放在**同一个物理硬盘**上，避免跨盘复制；
- 别在导出时用微信大量收发消息（会产生新库页，增加校验失败重试）。

慢不等于卡死。看进度条和日志框有没有在动；如果**10 分钟以上**完全没变化，再按 [USAGE.md 第七节](USAGE.md#七失败了怎么办) 排查。

## Q7 导出的 HTML 里图片打不开 / 显示"未找到本地文件"

按可能性排序：

1. **没勾"导出图片/文件"**。HTML 页面只是引用 `media\会话名\` 下的文件，没收集当然没有。重新导出并勾上这个选项。
2. **只勾了 CSV/JSON，没勾 HTML**。媒体收集目前只在勾选 HTML 时进行（因为只有 HTML 会引用这些文件）。想要图片，请把 HTML 一起勾上。
3. **原图本来就不在本机**。微信的图片有"过期未下载"机制：对方发了图，你没点开、或者清理过缓存，本机就只有缩略图甚至什么都没有。这种情况工具会显示 `[图片·未找到本地文件]`。
4. **看到的是 `.wxgf` 链接而不是图片**。这是 HEVC 编码的图，工具没有内置解码器，只做原样还原。浏览器大多不能直接显示 HEVC，需要你用支持 HEVC 的工具打开。详见 [MEDIA.md](MEDIA.md)。
5. **页面能打开但一片空白**：多半是只复制了 `.html` 文件、没带上同目录的 `style.css` 和 `media\`。整个输出文件夹要一起移动。

## Q8 为什么语音导不出来？页面写"未找到本地文件"

微信桌面版**默认不把语音存成本地音频文件**。你在电脑上收听的语音，数据从服务器流式拉取后播放，缓存随时清理，`msg\voice` 目录经常是空的。

工具的处理是：能在 `msg\voice` 里按消息的 md5 找到原始文件就复制出来，找不到就在页面上标注"未找到本地文件"。即使找到，桌面端的语音是 **SILK v3** 编码，工具做了格式识别但**不做音频解码**，所以你拿到的是原始数据而不是能直接双击播放的 `.mp3`/`.wav`。

**想听怎么办**：在微信里直接点那条语音播放，或用手机端。如果一定要落到本地，需要自己用外部工具（例如 ffmpeg）把 SILK 转成 wav——这属于工具之外的加工，本工具不提供。

## Q9 Excel 打不开 CSV / 打开是乱码

**先说结论：默认导出的 CSV 是 UTF-8 带 BOM 的，双击就能正常打开。**

CSV 表头是固定的 7 列：

```
时间, 发送者, 类型, 内容, 链接/文件, local_id, local_type
```

**如果还是乱码**，通常是这些情况：

- 用了很老的 Excel（2007 以前）或某些国产表格软件的旧版本，对 BOM 识别不好：用「数据 → 从文本/CSV」导入，编码选手 **UTF-8**。
- 双击时被系统关联到了记事本——那是文本编辑器不是表格软件，用 Excel/WPS 打开。
- 你打开的是别人二次转存过的文件（比如从别的工具导出的 GBK 文件），那不是本工具的产物。

**其他 CSV 注意事项**

- 一个会话一个 CSV，不是所有会话合在一张表里；想合并，自己在新表里「数据 → 获取数据 → 从文件夹」合并，或直接用 JSON。
- 内容里带换行的消息在 CSV 里会占多行显示，这是 CSV 格式本身的规定（字段被引号包裹），Excel 会正确识别成一条。
- 超过 104 万行的超大会话，Excel 装不下（单表行数上限），此时请改用 JSON 或拆时间段导出（命令行 `--since` / `--until`）。

## Q10 中文乱码 / 文字变成问号方块

| 文件类型 | 编码 | 说明 |
| --- | --- | --- |
| `.csv` | UTF-8 **带 BOM** | 专为 Excel 兼容，双击不乱码 |
| `.html` `.json` `.txt` | UTF-8 无 BOM | 现代浏览器、编辑器、VS Code 都能正认识别 |

工具**不会**输出 GBK/GB2312。如果看到乱码：

- 用记事本打开正常、Excel 打开乱码 → 是 Excel 的导入编码问题，按 Q9 用「从文本导入」选 UTF-8；
- 用某些老版本编辑器打开 `txt` 乱码 → 在编辑器里手动把编码设为 UTF-8；
- **所有格式都乱码** → 检查是不是解压工具/同步盘把文件转码了。请用 7-Zip 或资源管理器原生解压，别用会"智能转码"的网盘客户端直接打开。

字体缺字（罕用汉字显示成方块）是系统字体问题，与导出无关，装个更全的中文字体即可。

## Q11 我有多个微信号，能都导出吗？

**能。** 同一台电脑登录过的每个账号，都在数据目录下有自己的文件夹（名字形如 `wxid_xxx_9f3a`），工具会把它们全部列在第 2 步的**账号**下拉框里，一行一个。

操作：选一个账号 → 导出 → 回到第 2 步 **换另一个账号** → 再导出一次。建议两次用不同的输出目录，避免文件混在一起。

注意事项：

- 切换账号后要重新点 **加载会话列表**，因为会话索引是按账号缓存的；
- 密钥也是按账号缓存的（存在同一个 `keys.dat` 里，DPAPI 加密），所以第二个账号的首次导出同样需要该账号**正在登录**；
- 如果某个账号从来没在这台机器上登录过，它不会出现在列表里——本工具不读取云端数据。

## Q12 换一台电脑还能用吗？把导出结果拷走行不行？

分两件事：

**① 程序本身**：能。把整个 `WeChatExport\` 文件夹拷到新电脑（x64 Windows）双击就能用，不需要装任何东西。

**② 密钥缓存 `keys.dat`**：**不能跨机使用**。这个文件用 Windows DPAPI 加密，密钥材料绑定当前 Windows 账户与机器。拷到别的电脑、或同一台电脑换个 Windows 用户，都解不开——工具会自动忽略它、重新走内存扫描。这不是限制，是设计：防止缓存文件被复制后泄露密钥。

**③ 导出结果**：能。HTML/CSV/JSON/TXT/XLSX 都是普通文件，拷到任何机器都能打开。**但请把整个输出文件夹一起拷**（含 `style.css` 和 `media\`），否则 HTML 里的图片会失效。

**换电脑后想在新的机器上导出新聊天**：在新机器上登录微信，重新跑一遍流程即可，第一次同样需要 1–3 分钟取密钥。

## Q13 需要管理员权限吗？

**不需要，而且不建议。**

普通用户双击即可完成全部功能。原因：工具只需要读**当前用户**能访问的文件（微信数据目录本来就在你自己的用户目录下或在你有权限的盘符上），只需要读**同一个用户**启动的微信进程。

**用管理员身份运行反而更容易失败**：提权后进程处在不同的完整性级别，可能读不到普通权限运行的 `Weixin.exe` 的内存，于是报"未检测到正在运行的微信进程"或"未能在微信进程内存中找到密钥特征"。

**什么情况下必须提权**：几乎没有。除非你把微信数据目录放在了需要管理员才能读的位置（例如另一个用户的配置目录），那种情况正确做法是改数据目录位置，而不是提权。同理，也**不要**用"以其他用户身份运行"。

## Q14 数据会被上传吗？会不会联网？

**不会。一次网络请求都没有。**

可以自己验证：

- 程序只调用 `http.server` 在 `127.0.0.1` 上起服务（回环地址，外部网络不可达），端口是随机的；
- 代码里没有任何 HTTP 客户端、上传逻辑或遥测；`core`、`export`、`web` 三个包里没有对外请求；
- **拔掉网线/关掉 WiFi 也能完整使用**，这就是最直接的自证。

**数据留在哪里**

| 数据 | 位置 | 生命周期 |
| --- | --- | --- |
| 解密后的临时数据库 | `%LOCALAPPDATA%\WeChatExporter\work\` | 导出成功后自动删除；异常中断时可能残留，需手动清理；命令行设 `WEXPORT_KEEP_WORK=1` 则保留 |
| 密钥缓存 | `%LOCALAPPDATA%\WeChatExporter\keys.dat` | 长期保留（DPAPI 加密，仅当前 Windows 用户可解） |
| 导出结果 | 你指定的输出目录 | 永久，**由你负责** |

**最后一个提醒**：上传风险不在工具，而在导出之后。导出的 HTML/CSV 是**明文**，包含你和对方的真实对话、昵称、时间、文件。不要随手发到群里、传到网盘公开链接、或提交给来路不明的"恢复服务"。要分享，请先脱敏。
## Q：导出时提示「PermissionError: [WinError 5] 拒绝访问」怎么办？

这是 Windows 的**受控文件夹访问**（勒索软件防护）拦截了未签名的 `WeChatExport.exe`，
常见于默认的「文档」目录。三种处理方式任选：

1. 在「输出目录」里改成 `D:\微信导出` 这类不在受保护范围内的路径；
2. 到 Windows 安全中心 → 病毒和威胁防护 → 勒索软件防护 → 受控文件夹访问 →
   「允许应用通过受控文件夹访问」，把 `WeChatExport.exe` 加进去；
3. 直接留空输出目录：新版会依次尝试「文档\微信导出 → 程序目录\导出 → 本地应用数据」，
   自动落到一个可写位置，并在界面上显示最终路径。
## Q：为什么自定义目录（D:\、E:\）都提示无法写入，只有留空才能导出？

如果程序被解压到带有“低完整性”标记的受限目录（例如某些工作区、临时解压目录），
Windows 会以低权限启动它，导致它只能写自己所在目录和临时目录，写 D:\、E:\ 或“文档”都会被拒绝。
处理办法：把整个 `WeChatExport` 文件夹**复制到普通目录**（如 `D:\微信导出工具`）后重新运行。
界面检测到这种情况会显示黄色警告条，按提示移动即可。
