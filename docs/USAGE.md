# 使用说明（WeChatExport 1.0.0）

本文按界面顺序讲一遍完整流程。界面是一个**本地网页**，不需要联网，也不可能被别人看到——它只监听本机 `127.0.0.1`。

> 术语说明：「会话」指左边那一栏的聊天对象，可以是一个人，也可以是一个群。

---

## 一、启动

1. 确认微信 **4.x 已经登录，并且窗口没收掉**（最小化可以，退出登录不行）。
2. 双击 `WeChatExport.exe`。
3. 会同时出现两个东西：
   - 一个**黑色控制台窗口**，里面印着一行 `微信聊天记录导出工具已启动：http://127.0.0.1:xxxxx/`。这是程序本体，**导出期间不要关**。
   - **默认浏览器**自动打开这个地址，显示工具的网页界面。

如果浏览器没有自动弹出，手动复制控制台里那行网址，粘到浏览器地址栏回车即可。端口每次启动都是随机的，所以旧书签会失效，请以控制台显示为准。

界面顶部有一条标题栏：

```
💬 微信聊天记录导出
仅在本机运行 · 数据不上传 · 支持微信 4.x                          [退出]
```

右上角的 **退出** 会关掉本地服务并结束程序。窗口底部的灰色小字是隐私提示。

---

## 二、第 1 步：检测环境

界面上的第一张卡片长这样：

```
① 检测环境
[自动检测微信与账号]   点击后自动查找微信安装位置与聊天数据
```

点这个蓝色按钮。等待几秒，卡片下方展开一张表：

| 项目 | 正常表现 | 异常表现 |
| --- | --- | --- |
| 微信版本 | `4.1.15.51` 之类的版本号 | `未检测到`（红色） |
| 安装目录 | 微信的安装路径 | `—` |
| 运行状态 | `正在运行`（绿色） | `未运行（请先登录微信再导出）`（黄色） |
| 数据目录 | 一个或多个路径，多个用「；」隔开 | `未找到` |
| 账号 | `1 个`、`2 个`…… | `未找到`（红色） |
| 提示 | 仅在有问题时出现 | 例如"未定位到 Weixin.dll，密钥自动恢复可能不可用" |

按钮右侧的文字会变成 **检测完成，请继续下一步**；如果没找到账号，则是 **未找到账号，请确认微信已登录过**。

> 只要出现"未运行"或"未找到账号"，**先不要往下走**。打开微信登录，回到这一步重新点一次按钮。原因和处理办法见 [FAQ](FAQ.md) 的 Q1–Q4。

检测通过后，第 2、3 步的卡片会自动出现。

---

## 三、第 2 步：选择账号与会话

```
② 选择账号与会话
账号   [ wxid_example_9f3a  （3 个消息库）  ▼ ]
会话   [加载会话列表]  ☑ 全部会话     默认导出全部会话
```

**账号**下拉框：每个选项是一行"账号 + 消息库数量"。同一个微信登录过多个号，这里就会有多项。括号里的数字是数据库分片数，几十个也正常。

**要不要加载会话列表？**

- **不需要挑会话** → 什么都不用点，保持 **全部会话** 勾选，直接去第 3 步。这种做法最快，因为不需要提前解密。
- **只想导出某几个会话** → 点 **加载会话列表**。这一步会取密钥并解密数据库，**首次大约 1–3 分钟**（密钥缓存过之后会快很多）。期间提示文字是"正在读取会话（首次需解密，可能要 1–3 分钟）…"。

加载完成后，下方出现会话清单，每行是：

```
☑  张三          群聊 · 2026/10/19 21:03
☑  文件传输助手
☐  某某（置灰，无法勾选）    ← 该会话没有可读消息
```

- 每行一个复选框 + 会话名 + 「群聊 ·」标记 + 最后一条消息的时间。
- 置灰的行表示数据库里查不到这个会话的消息表，勾了也导不出内容。
- 取消勾选 **全部会话** 之后，勾选才会生效。
- 会话数量文字会变成 **已加载 N 个会话，可勾选需要导出的会话**。
- 勾错了想重来：重新勾上 **全部会话**，会把所有可选行一次性勾满。

> 注意：**只勾了 0 个会话、同时也没勾"全部会话"** 时，程序会按"全部会话"处理，不会导出空结果。

## 四、第 3 步：导出设置并开始

```
③ 导出设置并开始
格式   ☑ HTML（可离线浏览）  ☐ CSV  ☐ JSON  ☐ TXT  ☐ Excel
       ☑ 导出图片/文件   ☑ 包含系统消息
输出目录 [ 默认：文档\微信导出\日期时间                ]
[开始导出]   [打开输出目录]（完成后出现）
```

### 选项逐项说明

**格式**（可多选，至少选一个；一个都不选会弹窗提示"请至少选择一种导出格式"）

| 勾选 | 得到什么 | 适合谁 |
| --- | --- | --- |
| HTML | 每个会话一个网页 + 一份总目录 `index.html`，图片直接嵌在页面里，双击就能离线看 | **推荐**。想"像微信一样翻着看"就选它 |
| CSV | 每个会话一个 `.csv`，Excel/WPS 直接双击打开，一行一条消息 | 想做筛选、统计、交给律师整理时间线 |
| JSON | 每个会话一个 `.json`，字段最全，含消息 id、原始类型、附加信息 | 要写脚本二次处理 |
| TXT | 每个会话一个 `.txt`，纯文本，`[时间] 发送者: 内容` | 想直接全文搜索、导入笔记软件 |
| Excel | 每个会话一个 `.xlsx`，带表头加粗和冻结首行 | 想要"打开就是表格"，懒人友好 |

**导出图片/文件**：勾上才会把图片解密还原、把文件复制到导出目录（放在 `media\会话名\` 下）。取消勾选则只导出文字，速度快很多、体积小很多。**注意：只有同时勾了 HTML，媒体才会被收集**。

**包含系统消息**：像「你已添加了张三」「某某撤回了一条消息」这类。取消勾选可以去掉它们。

**输出目录**：见下面第五节。

### 开始与进度

点 **开始导出** 后，按钮变灰，下方出现进度条和三行信息：

- **进度条**：整体百分比。取密钥阶段走得慢是正常的。
- **阶段文字**：形如 `正在解密 message\message_0.db（3/12）（45%）`。
- **日志框**：最近的操作记录，滚动显示。

完成后，阶段文字变成：

```
完成：N 个会话，输出到 D:\备份\微信\20261020-103355
```

同时出现 **打开输出目录** 按钮，点它会用资源管理器打开那个文件夹。此时**临时解密副本已被自动删除**，微信原文件一个字都没动。

想再导一次别的格式，改选项再点 **开始导出** 即可；同一个账号第二次会复用已解密的会话索引，快很多。

## 五、输出目录怎么定

### 默认位置

**输出目录**留空时，导出到：

```
C:\Users\<你的用户名>\Documents\微信导出\20261020-103355
```

即「文档\微信导出\年月日-时分秒」。每次导出独立一个文件夹，不会互相覆盖。

### 自己指定

在输入框里填一个完整路径，例如：

```
D:\备份\微信\2026-10月
```

规则：

- 目录**不存在会自动创建**（包括中间层级）；
- 已存在且非空也**不会覆盖或清空**，新文件会写进去；同名文件会被本次导出的同名文件替换；
- 建议用**纯中文/英文/数字**路径，避免 `:` `*` `?` `"` `<` `>` `|` 这些字符；
- 不要选微信自己的数据目录（如 `D:\WeChat\xwechat_files`），也不建议选系统盘根目录；
- 路径不要太长。会话名本身可能很长，Windows 整条路径超过约 260 字符时会写文件失败。

### 导出后目录里有什么

以同时勾了 HTML + CSV 为例：

```
20261020-103355\
├─ index.html              会话总目录，从这里点进去
├─ style.css               页面样式（和 html 放一起才好看）
├─ 张三.html               每个会话一个页面
├─ 张三.csv
├─ 产品讨论组.html
├─ 产品讨论组.csv
└─ media\
   ├─ 张三\
   │  ├─ <一串 md5>.jpg    解密还原后的图片
   │  └─ 合同.pdf          聊天里收到的文件
   └─ 产品讨论组\
      └─ ...
```

- 文件名取自会话的**备注名**，没有备注才用昵称，其中的 `\ / : * ? " < > |` 会被剔除。
- 如果两个会话的显示名完全一样（例如两个不同的人被你改成了同一个备注），它们的文件会互相覆盖。想让两者都留下，请先给其中一个设置不同的备注名再导出。
- 图片文件名是一串十六进制（原始资源名），不携带聊天内容。
- 聊天里收到且已保存到本机的视频、文件会原样复制进同一个 `media\<会话名>\` 目录（例如 `video.mp4`、`合同.pdf`）；本机没有原件的，页面上标注"未找到本地文件"。
- 只勾 CSV/JSON/TXT/Excel 而**不勾 HTML** 时，不会生成 `media\` 目录——这几种格式本身不引用媒体文件。
- 若某张图是 HEVC 编码（`.wxgf` 文件），页面里不会内嵌显示，而是一个可点击的链接，点开是原始文件，需要你自己用支持 HEVC 的播放器/转换工具查看。详见 [MEDIA.md](MEDIA.md)。

## 六、只导出某一个会话

有两条路，任选：

**路线 A：界面上勾选（推荐）**

1. 第 2 步点 **加载会话列表**，等解密完成；
2. **取消勾选「全部会话」**；
3. 在清单里只勾你要的那一个会话；
4. 第 3 步点 **开始导出**。

**路线 B：命令行**

```powershell
WeChatExport.exe --export --account wxid_example_9f3a --out "D:\备份\张三" --formats html --chats wxid_of_the_chat
```

`--chats` 后面填会话的 username（不是备注名），多个用逗号分隔。不确定 username 时，用 `--scan` 看不到会话级信息，建议还是走路线 A。

## 七、失败了怎么办

界面上的失败会显示成红色文字，形如 `失败：RuntimeError: 数据库解密失败，请确认微信已登录且版本为 4.x`。先按下面的表对号入座，再去看 [FAQ](FAQ.md) 的详细解释。

| 界面提示 | 最可能的原因 | 怎么办 |
| --- | --- | --- |
| `未找到微信账号目录` | 数据目录在非常规位置，或微信从未登录过 | 先登录微信；确认数据目录（见 FAQ Q2） |
| `未检测到正在运行的微信进程，请先登录微信后重试` | 微信没开，或登录的是另一个 Windows 用户 | 登录微信，用同一个 Windows 账户运行工具（FAQ Q4） |
| `未能在微信进程内存中找到密钥特征，请确认微信为 4.x 且已登录` | 微信是 3.x，或版本特征变了 | 确认版本；升级/降级工具（FAQ Q3、Q11） |
| `候选密钥均未通过校验（客户端版本可能已变更）` | 微信刚升级，内存特征不匹配 | 同上，或用手动密钥 |
| `未找到微信客户端 DLL，无法完成密钥恢复` | 只找到 exe 没找到 `Weixin.dll` | 重装微信到默认路径后重试 |
| `该账号目录中未找到可用数据库` | 账号目录是空壳（登录过但没同步过消息） | 换一个账号，或让微信先同步消息 |
| `数据库解密失败，请确认微信已登录且版本为 4.x` | 密钥不对，或微信正在写库 | 退出微信再重登一次，重试；仍失败见 FAQ Q3 |
| `手动密钥与该账号数据库不匹配` | 密钥属于别的账号 | 换对应账号的密钥 |
| `已有任务在运行` | 上一次导出还没结束就点了第二次 | 等进度条走完 |
| `读取会话失败：...` | 解密中途失败 | 看日志框最后几行；带 `WEXPORT_DEBUG=1` 重启可看详细原因 |
| 进度条卡在取密钥阶段很久 | 正在校验大量候选密钥，属正常 | 首次 1–3 分钟；超过 10 分钟按取密钥失败处理 |
| 双击 exe 后什么都没发生 | 被杀软拦截，或浏览器未关联 | 看控制台窗口是否有报错；手动访问控制台打印的网址 |

### 排查三件套

1. **看控制台窗口**：程序本体在那里，异常信息会打在最上面。
2. **开调试日志**：关掉程序，用命令行启动

   ```powershell
   set WEXPORT_DEBUG=1
   WeChatExport.exe
   ```

   出错时界面会带完整调用栈，日志框也会更详细。

3. **保留临时文件**（命令行模式才有用）：

   ```powershell
   set WEXPORT_KEEP_WORK=1
   WeChatExport.exe --export --account wxid_example_9f3a --out D:\备份\test --formats html
   ```

   结束后 `%LOCALAPPDATA%\WeChatExporter\work\` 里会留下解密副本，可以自己用 SQLite 工具打开看。**排查完请手动删掉这个目录**——里面是明文聊天记录。

### 一定要说的话

- 程序**不会**修改、移动、删除微信的任何文件；失败了也不会有副作用，重试即可。
- 程序失败时**也会**清理临时目录（GUI 模式）。
- 如果反复失败，把「检测环境」那张表的内容（版本、安装目录、运行状态、数据目录）连同错误文字一起反馈，比截图聊天列表有用得多。

## 自动取密钥失败时：查看/手动填写密钥

在解压目录打开命令行（地址栏输入 `cmd` 回车），执行：

```powershell
WeChatExport.exe --dump-key
```

成功时会输出一行 JSON，其中 `key` 字段就是 64 位十六进制密钥。把它粘贴到界面第 2 步的
「密钥」输入框，再点「加载会话列表」即可。也可以直接用于命令行导出：

```powershell
WeChatExport.exe --export --account <账号目录名> --out D:\out --formats html --key <64位hex>
```

说明：微信 4.x 没有把密钥存放在固定的配置文件中，它只在登录运行时的进程内存里，
所以“手动获取”本质上仍要借助本工具的内存扫描；`--dump-key` 会把结果打印出来，
方便在自动流程异常时手工兜底。密钥只在本机使用，不会上传。
